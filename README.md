# dissonant

A cross-platform DAW that shows you which notes sound good. The piano roll re-tiers every
note in real time against the chord that's playing — **solid** chord tones, **spicy** tensions,
**flagged** dissonance — so a player without theory can write, arrange and finish a track.
Dissonance is always labeled, never blocked.

Rust audio engine + TypeScript UI, packaged with Tauri for macOS, Windows and Linux.

```
crates/dissonant-core     model · theory · chord track · document + undo        (pure Rust, tested)
crates/dissonant-engine   sample-accurate scheduler · synth · drums · mixer · render (Rust, tested)
crates/dissonant-plugins  CLAP: find installed plugins, host them                (Rust, tested)
crates/dissonant-catalog  curated free-plugin catalog · checksum-pinned installer (Rust, tested)
src-tauri                 desktop shell: commands, playhead events, file I/O, export
ui                        Vite + React + TypeScript: piano roll, chord lane, drums, song, mixer
docs                      brainstorms, plans, decisions
legacy/swift              the original macOS prototype (frozen)
```

## Run it

Prerequisites: [Rust](https://rustup.rs) (stable), [Node 20+](https://nodejs.org) with
`pnpm` (`corepack enable`), and the Tauri system deps for your OS:

- **macOS**: Xcode command-line tools.
- **Windows**: Microsoft C++ Build Tools and WebView2 (preinstalled on Windows 11).
- **Linux (Debian/Ubuntu)**:
  `sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev librsvg2-dev libasound2-dev patchelf pkg-config`

```sh
pnpm install            # root: tauri cli
pnpm --dir ui install   # ui deps
pnpm dev                # runs the Vite dev server + the Tauri app with hot reload
pnpm build              # production bundle + installer in src-tauri/target/release/bundle
```

UI-only, in a browser (no audio, in-memory mock of the backend — handy for design work):

```sh
pnpm ui                 # http://localhost:5173
```

## Using it

dissonant opens on a **new-project screen**: start from a **vibe** (amen jungle, dubstep, blown
out, rage, jersey club, hyperpop, pluggnb — each one sets tempo, key, swing and chords, then
builds a bass line, a chord part and a drum pattern on its own kit, leaving the lead track empty
for you), the **starter** (I–IV–V–vi in C with a melody and drums), an empty
project, one of your templates, or a recent file. The chord bed starts on so space plays music
straight away. Turn the screen off in Settings → editing; File → New from a vibe or template…
brings it back, and ⌘N makes a starter or empty project per the same settings tab.

Five screens, switched with the **SETUP | PAT | SONG | GTR | SOUND** control (Tab cycles PAT and
SONG).
Shortcuts are written for macOS; on Windows and Linux read Ctrl for ⌘, Alt for ⌥ and Shift for ⇧
(the app's own labels do this for you):

| Where | How |
|---|---|
| **SETUP** · the song | key, tempo and swing, the song's chord progression and its length in bars, and the sections that divide it — the page to shape a song on before writing a note · each section carries its own extent, and the list's ↑ ↓ ⧉ buttons move or copy a section *with the music inside it*, in one undo step |
| Layout | drag the seam between any two panels to resize them — the track list, the inspector, the song's track column, the devices panel, the audio track list, the sound list · double-click a seam to put it back, arrows nudge it when it has focus (⇧ faster) · sizes are remembered per machine |
| Tracks and patterns | every pattern belongs to one track: the track → pattern tree on the left adds, renames, duplicates and deletes patterns, and drags them onto the song on their own track's lane · a pattern's length is the 1/2/4/8-bar chips **or the bars field beside them**, so a 3-bar loop or a 16-bar build is one number away (tree foot and inspector both) |
| **PAT** · piano roll | click places a note (keep dragging to move it) · drag a note to move (press ⇧ mid-drag to lock an axis), its right edge to resize · **⇧-drag a note steps its length through the note values** (1/16 → 1/8 → 1/4 …; ⇧-click still toggles the selection) · ⌥-drag a note duplicates · ⌥ on empty space places off the grid (or paints, per Settings) · **brush** paints · ⇧/⌘-drag marquee · double-click a key selects that pitch (⌘: pitch class) · Tab/⇧Tab next/previous note · right-click erases · ⌫ ⌘A ⌘C ⌘X ⌘V ⌘D · ⇧⌘E split at playhead · ⌘J glue · ⌘B duplicate one loop later · 0 mute (hollow, not played) · arrows nudge (⇧ = octave / bar, ⌥ = fine) · `[` `]` velocity · ⌥-wheel transposes (⌥⇧ octaves) · ⌘-wheel zooms at the cursor · ⇧-wheel scrolls · velocity lane: drag the stems, ⌥-drag draws a ramp · click the ruler to seek · drag the ruler's top strip for a loop region (right-click clears) · **snap** is grouped straight / triplet (`T`) / dotted (`.`) — 1/8T and 1/16. are exact at 960 ticks a beat · **follow** keeps the playhead in view · **fit** zooms to the pattern, and every zoom (roll, song, SETUP) is remembered per machine · **fold** shows only rows with notes (plus nearby chord tones) · **ghost** plays and draws another pattern behind yours, dashed, with its tiers and its own volume · hover a cell for a plain-words explanation · **tiers** tints rows by fit, **map** paints the whole progression · HARMONY → select by tier picks every chord tone / tension / dissonant note · NOTES → length chips and mute for the selection |
| Note properties | every note carries the performance set the piano roll's lane edits: **velocity · panning · fine pitch · release · mod X · mod Y · shift · repeats** (plus a colour group) · pick one in the lane under the roll, drag a stem to set it, drag across stems to paint, ⌥-drag to ramp a line through them, `[` `]` to nudge · **shift** moves only where the note sounds, so it keeps its grid cell and a tick marks where it belongs · **repeats** retriggers the note inside its own length, drawn as divisions in the note body · mod X is the note's filter cutoff and mod Y its resonance, both offsets from the track's own tone · **pitch envelope**: a bend drawn inside the note body, one row = 100 cents, on top of fine pitch — double-click adds a point, drag moves it (⇧ fine), ⌥-click flips glide / jump, right-click removes, up to 16 points · the engine follows it per sample, hosted CLAP instruments hear it as note expression |
| Transform | inspector → TRANSFORM: quantize, humanize (chord tones stay tighter), legato, arp ↑/↓/⇅/random, strum, chop, ×2 slower / ½ faster, reverse, invert · three dials under the grid: **strength** is how far quantize pulls a note to the grid (100% is dead on it, less keeps the hand that played it), **drift** and **vel ±** are how far humanize moves a start and a velocity · Edit menu: transpose by semitone / octave, split, glue, duplicate-loop, mute · **magnet** pulls placed/dragged notes to the nearest chord tone · **stamp chord** places the chord under the cursor |
| Resolve / keep | select one dissonant note: the inspector says why, offers ↓/↑ resolve targets, or **keep** marks it deliberate (hatch stays, the "!" goes) · a note that bends keeps the tier of where it starts and wears a folded corner, and the inspector says so |
| Chord lane | progressions live under HARMONY in the inspector, named by mood ("sad but hopeful") with the chords they write in your key; the list follows the key's scale · the progression is the song's, so the lane edits it wherever you are · drag a chord to move, its right edge to resize · click to free-build · right-click to delete · **chords** to hear the bed |
| Play live | **KEYS** tier: home row = chord tones, top row = tensions of the chord under the playhead, remapped as it moves · chrom: Z/Q rows chromatic · −/+ octave · **MIDI IN** picks a controller · **REC** (R) while playing writes what you play into the pattern, quantized to the grid |
| Key | place notes and the KEY cell offers "X? lock" · × unlocks · or pick root + scale under HARMONY · a section with its own key modulates the patterns inside it · chords detected in a strummed take count as evidence too |
| Drums | the grid's rows are the track's own **kit**: each pad names a sound, ▾ swaps it, **+ add sound** adds a pad at the GM pitch that suits the sound (a snare on 38, an open hat on 46 sharing the closed hat's choke group) · left-click/drag adds hits, right-click removes · the step is whatever snap says, triplet and dotted grids included · the grid is one turn of the pattern · a step is a note, so its brightness is its velocity and it leans when shifted · **⇧-drag picks hits** (⇧⌘ adds) and the picked row copies, cuts, pastes, duplicates one selection later, deletes and nudges — ⌘C ⌘X ⌘V ⌘D, ⌫, ← → a step (⇧ a bar), ↑ ↓ to another pad; the clipboard is the piano roll's, so hits move between them · click a row's name to aim the **graph editor** below the grid: it edits the same properties as the roll's lane (drag to set, ⌥-drag to ramp) · the tool row fills every 2/4/8 steps, clears, rotates ◀ ▶, randomises, or writes a **euclidean** rhythm from an onset count and rotation |
| Take → notes | an audio clip on the song has a **notes** button that transcribes its raw DI (never the rig, its gate or its trim), off the UI thread: single notes land on a new synth track named after the take ("take 3 notes") with the default sound, one pattern spanning the clip at the clip's position; a repeated pick is two notes, a hammer-on is a new note, a bend or a slide stays one note with a pitch envelope, velocity follows how hard each note was picked · strummed parts are **refused** — no notes are written there and the toast says how much was refused — and offered instead as chords in a **heard** lane under the progression: ✓ puts one on the progression (trimming what it lands on), ✕ or right-click dismisses it, one undo step each; nothing reaches the progression until accepted · the whole transcription is one undo step |
| **SONG** · arrangement | **tempo lane** under the ruler: double-click adds a tempo change at that beat, drag a point up/down for bpm (⇧ fine) and sideways to move it, ⌥-click makes it a ramp (a glide from the previous tempo), right-click removes; the transport clock and the engine follow the map, pattern mode plays at the base tempo · **automation**: the chip beside a track's M/S opens a sub-lane for its **volume · pan · tone · reverb send**, drawn with the same gestures as the tempo lane (double-click adds, drag moves — ⇧ fine — ⌥-click flips ramp/step, right-click removes, **clear** empties the lane); a point with a ramp glides into itself and a stepped one holds, a whole freehand drag is one undo step, the lane overrides the fader while it exists, and the engine ramps it per sample so a fade never zippers — the offline export hears exactly the same lanes · each track has its own lane and plays its own patterns · drag a pattern from the tree onto a lane, or ＋ on a pattern to append a clip · **snap** picks the grid clips move, trim and drop on (bar · 1/2 · 1/4 · 1/8 · 1/16 · off) and ⇧ ignores it for one drag · drag a clip to move, its right edge to trim or loop-extend, ⌥-drag to copy, right-click for the menu, double-click to edit · select clips and move or delete them as a group, ⌘A ⌘C ⌘X ⌘V (at the playhead, back on their own tracks) ⌘D, **0 mutes** a clip — it stays on the timeline, drawn faint, and plays nothing — **unique** forks a clip's pattern · **follow** keeps the playhead in view while playing and stands down while you drag or scroll away by hand · **the loop brace** is the strip under the markers: drag it to set the loop, right-click it to clear, L (or the transport's loop button) turns looping on and off — the brace is saved with the project, so reopening a song keeps the chorus loop · the song has a hard end you set in SETUP, and clips and the loop are held inside it · double-click the ruler's top strip to add a section; click it to name it, give it a key or color; drag to move; right-click to remove · track headers: M/S, volume slider, meters · click the ruler to seek · **right-click the bar ruler** to insert, delete or duplicate time: insert opens N empty bars at that bar and pushes every clip, marker, tempo point, chord and automation point after it along; delete and duplicate work on the loop brace. Each is one undo step, and a clip the cut falls inside is split rather than stretched, so nothing changes what it plays · a section owns an extent (the bars it covers, 'auto' meaning up to the next marker), which is the band drawn behind it and the music SETUP's duplicate and reorder buttons move |
| **REC** · tracking | the page follows the **armed** track, so what you see is where the take will land · **input**: device and channel (moved off Settings, which keeps output, rate and buffer), arm, monitor, the grid a take snaps to, and a pre-rig meter with **peak hold** and a **CLIP** latch you clear with a click · **take alignment**: every take is pulled back by the output block + the input backlog + a **manual trim per input device** (ms, keyed by device name, saved with the settings), converted to ticks through the song's tempo map rather than one bpm — a correction that would run past tick 0 clamps there and trims the head instead, so the waveform stays on the grid, and the page says how far it moved ("aligned −12.4 ms") · **tuner**: a strip on this page only, silent while it is open (you tune the strings, not the amp), with a configurable **A4** and named tunings (standard, drop D, DADGAD, open G, half step down, bass) so it names the string that is flat rather than the note that is near · an armed track with no rig shows the input strip and no rack |
| the rig | the rack runs input strip → pedals → amp → cab → rack, and the amp is four separate choices rather than one preset: **model** across the top sets all of them at once (tweed combo, blackface, british blues, vintage stack, modern stack, boutique, high octane, pawnshop fuzz) and each click is one undo step · **amp** picks the preamp voicing, **eq** picks which passive tone stack the bass/mid/treble knobs drive (us classic, british, british bright, boutique) — the knobs load each other the way the circuit does, so closing the mid also moves the treble · **circuit** shows only the switches that amp's circuit actually has, one undo step each: a **bright** cap on the tweed and British voicings (a treble bypass across the gain pot, so it hands back most of the voice down low and nothing wide open), **half power** on the tweed (less headroom, deeper sag) and a cathode **follower** on the British ones (it squashes and conducts ahead of the tone stack); the fuzz voicing has none · the **power stage sags**: its supply rail falls under a hard chord and climbs back as you let go, deep on a tweed and barely at all on a modern head — baked per model, with nothing to set · **cab** picks the speaker and **mic** the microphone (dynamic, condenser, ribbon) · **pos x** walks the mic from the cone's edge to the dust cap, dark to bright, and **pos z** from against the grille (proximity bass, tight attack) to backed off · a **direct** cab is a DI sound and dims the mic controls, because there is no speaker to point one at |
| **SOUND** · sound design | a browser over 60 factory synth sounds and 55 drum sounds plus everything you have saved, grouped by character (basic, pad, pluck, bass, lead, keys …) · the **synth editor** is the patch the engine plays: two oscillators with detune and shape, a filter with its own envelope, two LFOs you can aim at pitch, cutoff or level, chorus and echo, drawn as an envelope view and a live scope · the **drum editor** shapes body, noise, metal and click per sound · play the audition keys to hear it, **randomize** or **mutate** to find one, then save it and use it on the track · the library is global (it follows you between projects); a sound a project uses that is not in your library travels inside the project file |
| Sounds on a track | inspector → INSTRUMENT: a synth track picks a sound (or a CLAP plugin) and **edit ↗** opens it on the SOUND page; a drum track shows its kit |
| Bottom panel | **DEVICES**: instrument, **inserts** (the track's effect chain), track bus (vol / pan / tone / reverb), **master inserts**, master (gain, cuts, 3-band EQ, reverb, **ceiling** and a **limiter** switch) · **MIXER**: faders, pan, meters, M/S · **PLUGINS**: the free-plugin browser |
| Effects | the **inserts** card holds up to 8 effects per track (and on the master), each with bypass, ▲▼ reorder and its own knobs — a track runs instrument → tone → inserts → gain → pan → reverb send, so inserts are pre-fader, and the master's run before its own strip · six **stock effects** need nothing installed: **EQ** (high-pass, low shelf, three sweepable peaks, high shelf, low-pass), **compressor** (threshold, ratio, knee, makeup, attack, release), **limiter** (the master's own lookahead design, with the ceiling on a knob), **saturator** (a 12AX7 stage, oversampled), tempo-synced **delay** and **reverb** · their values live in the project, so a mix opens the same everywhere, and the offline bounce is sample-for-sample what played |
| Plugins | a track's instrument picker lists the built-in voices, then every CLAP instrument found on this computer; picking one replaces the voice and its parameters appear below (drag to hear, release for one undo step) · an insert slot can hold a CLAP effect instead of a stock one, with the same knobs underneath · a project whose plugin is not installed keeps the name and says so instead of silently swapping it · every note goes out with its own id, and fine pitch and pitch envelopes reach the plugin as **note expression** (tuning), so a plugin that supports it bends with the roll · CLAP only, because CLAP is MIT like the rest of this project and every Rust VST3 binding is GPL-3.0 — the host is format-agnostic inside, so another format is additive |
| Plugin browser | **PLUGINS** in the bottom panel: a curated list of genuinely free plugins, searchable by what they sound like ("pad", "lo-fi", "drums") rather than by jargon · **install** downloads, checks the pinned SHA-256, unpacks and drops the bundle in your plugin folder, then rescans — a checksum that does not match installs nothing · plugins that only ship a `.dmg`/`.pkg` cannot be auto-installed and offer **open page** instead |
| Transport | space play/stop · Enter return to start · L loop · R record (the chip beside REC picks the grid a take snaps to, or **free** to keep it exactly as played; a take is one undo step, a second pass over a loop overdubs, and a note played where the pattern is not on the song is reported rather than folded in somewhere) · **punch**: drag a range in the strip under the song ruler (right-click clears) and an audio take drops in and out there with the count-in and pre-roll as its run-up; the take it lands on is split with 15 ms equal-power crossfades at both seams, all one undo step · loop is blocked while punch is armed, and the loop button says why · audio clips have **fade handles** on their top corners (equal-power) · M metronome (count-in and pre-roll when record is armed; volume in Settings) · BPM: click to type (↑↓ ±1, ⇧ ±10), drag up/down, scroll, double-click resets, ÷2 ×2 · tap tempo (last 8 taps) · SWING 50–75 on 8ths or 16ths (the roll shows where swung notes land) · SIG time signature · the master meter reads the mix **before** the limiter, so a hot mix reads hot rather than pinned, and **CLIP** latches the moment it goes over the ceiling — click it to clear · ⌘Z/⇧⌘Z undo/redo (the Edit menu names the step) · ⌘S save · ⌘O open · ⌘E export WAV (offline render, faster than real time) · ⌘, settings · ⌘Q quit |
| Files | **⌘E** export audio: song or pattern, loop count, chord bed, **stems** (one WAV per track), rate / depth / dither / normalize / tail, with a progress strip · File → Export MIDI (one MIDI track per track, chord names as markers; a track with bends or fine pitch is written MPE-style — one note per channel 2–16, ±48 semitone bend range — and every other track exactly as before) and Import MIDI into the selected pattern (new tracks, one undo step) · File → New from a vibe or template / Save as template (templates live in the app data folder) · unsaved changes are prompted on close, new and open · saving writes a sibling and renames it into place, so a failed save leaves the file you had — the one it replaced is kept as `<project>.bak` and the autosave stays until the save lands · autosave every 30 s while dirty (`<project>.autosave.json`, restore offered on launch) · File → recent files · drop a `.dissonant` on the window to open it · the engine restarts by itself when the output device changes or disappears |
| Settings (⌘,) | **audio**: output device, sample rate, buffer size with latency, test tone, engine load / xruns, metronome volume, count-in, pre-roll · **midi**: default input with auto-reconnect, velocity curve, channel, octave · **editing**: default grid / velocity, audition on place, ⌥ = no-snap or paint, confirmations, new-project defaults · **export**: rate, 16/24/32-bit, dither, normalize, tail · **appearance**: UI scale, row height, reduced motion, accent and tier colors (color-blind-safe preset) |

The look follows the UI handoff in `docs/design/2026-10-02-ui-handoff-violet.md` (violet accent, IBM Plex
Sans Condensed + JetBrains Mono, bundled). Controls only exist for features that are built; the
metronome, count-in, tools, ghost notes, CC lane, browser and plugin devices from the mock arrive
with their features.

Projects are JSON (`.dissonant`). The format is documented by `crates/dissonant-core/src/model.rs`.
Musical time is **integer ticks** at 960 per quarter note (`crates/dissonant-core/src/ticks.rs`), so
quantizing, loop tiling and note repeats are exact; audio keeps its own seconds. A file written
before schema 9 carried beats and is converted on open.
